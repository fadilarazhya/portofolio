# Portfolio - Fadila Razhya

Personal portfolio website.

## Tech Stack

- React 18
- TypeScript
- TailwindCSS 4
- Vite
- Flowbite

## Setup

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run dev      # Development
npm run build    # Production build
npm run preview  # Preview build
npm run lint     # ESLint
```
